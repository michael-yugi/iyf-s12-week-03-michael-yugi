# Daily Challenge 1: Terminal-Only Project Setup

## Description

This project demonstrates how to create a complete web development project structure using terminal commands only.

## Project Structure

* `src/index.html` – Contains the HTML page structure.
* `src/css/style.css` – Contains the styling.
* `src/js/app.js` – Contains the JavaScript functionality.

## Skills Practiced

* Creating directories using `mkdir`.
* Creating files using `touch`.
* Navigating project folders.
* Building a basic HTML5 page.
* Connecting CSS and JavaScript files.

## What I Learned

I learned how to create a project structure using terminal commands without manually creating folders or files.
