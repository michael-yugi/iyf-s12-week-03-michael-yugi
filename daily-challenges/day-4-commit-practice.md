# Day 4: Git Commit Message Practice

## Objective

Practise writing clear and professional Git commit messages.

## Commit Message Rules

* Use present tense.
* Start with an approved type followed by a colon.
* Keep the message under 50 characters.
* Use a clear description of the change.

## Commit Messages Practised

1. `Add: Create project gitignore`
2. `Add: Create terminal project structure`
3. `Docs: Document find command practice`
4. `Add: Create HTML boilerplate script`
5. `Docs: Record commit message practice`

## What I Learned

I learned how to write meaningful commit messages that clearly describe changes made to a project.
