# Task 5.1: Terminal Navigation Log

## Exercise 1: Basic Navigation

| Command | Purpose |
|---|---|
| `pwd` | Displays the current directory. |
| `ls` | Lists files and folders. |
| `cd ~/Documents` | Navigates to the Documents folder. |
| `cd ..` | Moves up one directory. |
| `cd ~` | Navigates to the home directory. |

## Exercise 2: Create Project Structure

| Command | Purpose |
|---|---|
| `mkdir my-project` | Creates the main project folder. |
| `cd my-project` | Opens the project folder. |
| `mkdir src` | Creates the source folder. |
| `mkdir src/css` | Creates the CSS folder. |
| `mkdir src/js` | Creates the JavaScript folder. |
| `mkdir src/images` | Creates the images folder. |
| `mkdir docs` | Creates the documentation folder. |
| `mkdir tests` | Creates the testing folder. |
| `New-Item README.md -ItemType File` | Creates README.md. |
| `tree /F` | Displays the folder structure. |
